X（旧Twitter）風の投稿カード画像をブラウザだけで作れるメーカー。

## 📖 概要

Bot版「Fake Tweet Bot」（mabu-bots/fake-tweet-bot）のレンダラを Canvas に移植したもので、レイアウト・配色・カウント表記（万/億）・時刻表記は Bot版と同一。

## ✨ 機能

- すべてクライアントサイドで処理する（入力内容はサーバーに送信されない）
- アバターは画像ファイルの指定（クリック／ドラッグ＆ドロップ）に対応。未指定時は表示名の頭文字で自動生成
- 表示名・ユーザー名・本文（最大300文字）・投稿日時を入力して、幅1200pxのPNGを生成・ダウンロード
- カウント（返信/リポスト/いいね/表示数）は空欄で固定値（2 / 9 / 37 / 1204）
- テーマはダーク／ライトの手動切り替え（既定はダーク、選択は端末に保存されます）
- PWA対応（ホーム画面に追加可能、オフラインでも動作）

### 隠し機能: Discordアイコン取得

通常の画面には表示されないパネルから、Discord のユーザーIDを指定してアイコン画像を取得し、そのままアバターに設定できる（表示名・ユーザー名も自動入力）。

- パネルの出し方: キーボードで「discord」と打つ／フッターのクレジットを2秒以内に5回タップ／URL パラメータ `?uid=<ユーザーID>`（自動取得まで実行）
- ユーザー情報の照会には外部API（japi.rest）を使い、画像は Discord CDN から直接読み込む。照会に送られるのは入力したユーザーIDだけ

## 📝 使い方

1. アバター画像を指定します（未指定の場合は、表示名の頭文字で自動生成します）。
2. 表示名・ユーザー名・本文・投稿日時・カウントを入力します。
3. 「画像を生成」を押すとプレビューが表示され、「PNGをダウンロード」から保存できます。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。Web 版と同じレイアウト・配色（X ダークモード風カード、幅1200px・高さ可変）・カウント表記（万/億）でツイート風画像を生成し、PNG で保存できます。アバター画像はファイル選択またはドラッグ＆ドロップで読み込めます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Nisetsui.exe` を生成
- Web 版との違い: フォントは Noto Sans JP の代わりに Yu Gothic UI を使用。隠し機能（Discordアイコン取得）は未収録

## 🛠️ 開発

- 描画の純ロジックは `js/render-core.js` に分離してあり、`npm test` で単体テストを実行できます（依存なし、Node 標準のテストランナー）。
- 構文チェックは `npm run check`。
